# FariaFx
ENG:
FariaFx is a lighting control software designed to integrate professional lighting systems with DJ software. Its goal is to provide support for VirtualDJ, Rekordbox, JBL PartyLight devices, and DMX-based lighting equipment.
PTBR:
FariaFx é um software de controle de iluminação desenvolvido para integrar sistemas de iluminação profissional a softwares de discotecagem (DJ). Seu objetivo é oferecer suporte ao VirtualDJ, Rekordbox, dispositivos JBL PartyLight e equipamentos de iluminação baseados no protocolo DMX.
