# FariaFx

## ENG

FariaFx is designed for DJs looking for an intuitive, easy-to-configure, and plug-and-play lighting system that delivers professional results and unique lighting experiences for every performance. It integrates with DJ software, aiming to provide support for VirtualDJ, Rekordbox, JBL PartyLight devices, and DMX-based lighting equipment.

The project is built upon research and studies involving reverse engineering of software such as JBL One, VirtualDJ, and Rekordbox, as well as experience gained from previously developed software projects.

## PT-BR

O FariaFx é desenvolvido para DJs que buscam um sistema de iluminação intuitivo, de fácil configuração e com conceito plug-and-play, mas que ainda proporcione resultados profissionais e experiências de iluminação únicas em cada apresentação. Possuindo integração com softwares de discotecagem (DJ). Seu objetivo é oferecer suporte ao VirtualDJ, Rekordbox, dispositivos JBL PartyLight e equipamentos de iluminação baseados no protocolo DMX.

O projeto tem como base pesquisas e estudos realizados por meio de processos de engenharia reversa em softwares como JBL One, VirtualDJ e Rekordbox, além da experiência adquirida no desenvolvimento de projetos anteriores.

# Visual References

## ENG

FariaFx uses the interfaces of widely adopted software such as Ableton Live 12, FL Studio 2024, and VEGAS Pro 2027 as visual references. These references aim to provide a comfortable user experience, making software navigation more intuitive and enjoyable.

## PT-BR

O FariaFx utiliza como referência visual as interfaces de softwares amplamente utilizados no mercado, como Ableton Live 12, FL Studio 2024 e VEGAS Pro 2027. Essas referências têm como objetivo proporcionar uma experiência confortável ao usuário, tornando a navegação do software mais intuitiva e agradável.
